# Куда класть медиа

Всё, что лежит в этой папке, попадает на сайт как есть — по адресу `/job_case_portfolio_k/media/…`. Обработка (сжатие, конвертация) делается **до** того, как файл сюда положен.

## Структура

```
public/media/
├── avatar/
│   └── head.mp4          ← видео-голова для первого экрана (K-5)
├── iq-auto/              ← папка кейса, имя = id кейса из src/content/works/
│   ├── cover.webp        ← обложка: видна в ленте на главной и на странице кейса
│   ├── case.mp4          ← видео кейса, если есть: заменяет обложку движением
│   ├── 01.webp           ← изображения галереи на странице кейса,
│   ├── 02.webp              порядок задаётся именами файлов
│   └── …
└── jobs/
    └── …
```

Имя папки кейса обязано совпадать с именем md-файла в `src/content/works/`. Сейчас это `iq-auto` и `jobs`.

## Как подключить положенный файл

Файл сам по себе на сайте не появится — на него нужно сослаться в данных кейса, `src/content/works/<id>.md`:

```yaml
poster: media/iq-auto/cover.webp      # обложка
video: media/iq-auto/case.mp4         # видео, если есть
images:                               # галерея
  - media/iq-auto/01.webp
  - media/iq-auto/02.webp
```

Пути **без ведущего слеша** — базовый адрес подставляется в коде (`src/lib/url.ts`). Абсолютный путь вида `/media/…` даст 404 на проде: сайт живёт в подкаталоге.

## Требования к файлам

| Что | Формат | Размер | Примечание |
|---|---|---|---|
| Обложка кейса | WebP | ширина 2680px, до ~150 КБ | пропорции 5:4, как слот в макете |
| Видео кейса | MP4 (H.264) | до 20 секунд, до 5 МБ | без звуковой дорожки |
| Изображения галереи | WebP | ширина до 2680px | порядок по именам: `01`, `02`, `03` |
| Видео аватара | MP4 (H.264) | до 2.5 МБ | белый фон, полный оборот 360°, постоянная скорость, бесшовный луп |

Имена файлов — только латиница, цифры и дефис. Кириллица и пробелы ломают пути на хостинге.

## ⚠️ Имя файла аватара

Код ищет строго `media/avatar/head.mp4` и `media/avatar/head-poster.webp`. Файл с любым другим именем сайт просто не увидит — молча, без ошибки.

Исходник от нейросети сюда класть нельзя: он приходит с двумя ключевыми кадрами на весь ролик, звуковой дорожкой и весом в десятки мегабайт. Перемотка по такому файлу рвётся, а вес уходит в историю git навсегда. Кладите исходник в `references/03_motion/` и скажите — перекодирую.

## Если файл не обработан

Кладите исходник не сюда, а в `02_Efforts/Website_portfolio/references/05_works/<кейс>/` и скажите об этом — сжатие и конвертация делаются отдельным шагом, вручную класть тяжёлые исходники в репозиторий не нужно.
